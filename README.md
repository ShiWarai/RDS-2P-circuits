# RDS-2P Circuits

Электрические схемы для робота [RDS-2P](https://github.com/ShiWarai/RDS-2P), разработанные для лабораторного и домашнего травления при помощи бытовой химии.

## Описание плат

- "Плата питания для RDS-2P" используется в заднем отсеке робота для обеспечения питанием компонентов робота.
- "Плата коммутации двигателей для RDS-2P.json" выполняет сугубо электрораспределительную роль и уменьшает кол-во проводов.

## Таблица требуемых компонентов

В рамках DIY-сборки и экономии времени для пайки предлагается использовать готовые платы, которые можно купить с маркетплейсов.
